# Mitate

Mitate は利用者の Mac で動く横断検索のアプリ。各サイトの内容を手元に索引し、画像の埋め込みと全文で引く。MCP サーバー `mitate` が次のツールを持つ。

| ツール      | 使いどころ                                                                                                                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `selection` | 利用者がビューワーで選んだ参考と、そのメモ。利用者自身の目で選んだものなので、最初に確かめる                                                                                                        |
| `search`    | 言葉で引く。番号付きのコンタクトシート 1 枚と、番号ごとの出典の一覧が返る。`kind` で画像・動画・文章に絞れる                                                                                        |
| `similar`   | Shot の id か、手元の画像ファイル（`image_path`）に見た目が近いものを引く                                                                                                                           |
| `view`      | 1 件を原寸で見る。動画は時刻付きのフレーム列で返るので、動きの順序と間合いが読める。HLS の動画は poster 1 枚になる。文章の Shot は保存してある本文が返る（全文とは限らないので、続きは url で読む） |
| `sources`   | サイトごとの件数とログイン状態                                                                                                                                                                      |

利用者はビューワーのタイルを、ファイルとしてチャットへドラッグして渡すことがある。パスが `…/Mitate/drag/<サイト>/<id>.jpg`（文章は `.md`）なら Mitate の Shot で、Shot の id は `<サイト>:<id>`（`%` の写しは戻す）。出典は `view` で、動画の動きは `view` のフレーム列で確かめる。

## 部品を作る・調整するときの手順

1. `selection` を呼ぶ。選ばれたものがあれば、それを主な参考にし、メモを利用者の意図として読む
2. 足りなければ `search` で引く。部品の名前と質を短い英語で並べると当たりやすい（`segmented control`、`toggle switch`、`date picker`、`empty state`、`dense data table`、`glass toolbar`、`hover card motion`）。日本語でも埋め込みで引ける。動きの参考が欲しいときは `kind: "video"` に絞る
3. 今の部品の見た目が分かっているなら、スクリーンショットを撮って `similar` の `image_path` に渡す。言葉にしにくい近さで引ける
4. コンタクトシートを見て、関係のある 2〜4 件だけを `view` で確かめる。全部を開かない
5. 参考を実装に移すときは、どの参考のどの点（余白の比率、角丸の入れ子、影の段、動きの間合い）を採るかを決め、出典の url を添えて利用者に伝える。値は参考から写さず、プロジェクトの design token に置き換える

## 守ること

- 参考は判断の材料で、写す対象ではない。ブランドの図形、ロゴ、写真をそのまま使わない
- `search` の `live` は Pinterest と X にも問い合わせる。両サイトは自動取得を規約で禁じていて、アプリが回数を制限している。言い換えを何度も試すときは `live: false` にして手元の索引だけで引き、最後の 1 回だけ `live` を使う
- コンタクトシートの番号と一覧の番号は対応している。参考を挙げるときは番号ではなく url で示す
- MCP が応答しないときは、アプリが起動していない可能性がある。ツールの呼び出しがアプリを起動するので、もう一度呼ぶ。それでも失敗したら、そのエラーを利用者に伝える
